🔍 Common Issues & Solutions

If all requests fail with network error:

Your Next.js server might not be running. Start it with npm run dev

If single requests work but concurrent fail:

The proxy at 127.0.0.1:3128 can't handle multiple connections. You need connection pooling or request queuing.

If you see "invalid_api_key" in error:

Your Anthropic API key is invalid or revoked. Generate a new one at console.anthropic.com

If requests timeout after 30s:

The proxy connection is hanging. Try restarting the proxy service.

If you see CORS errors:

Open this file from the same origin as your Next.js app, or run it through the Next.js public folder.
